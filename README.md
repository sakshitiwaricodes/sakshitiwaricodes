## 🧠 Engineering Philosophy

```python
def build_software(problem):
    understand(problem)

    architecture = design_for_scale(problem)

    system = implement(
        clean_code=True,
        security=True,
        maintainability=True
    )

    test(system)
    containerize(system)
    deploy(system)

    return "ship → measure → improve"
```
